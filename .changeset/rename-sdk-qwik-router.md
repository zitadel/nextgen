The Qwik meta-framework SDK is `@zitadel/sdk-qwik-router`, named after Qwik Router, which Qwik 2 renamed from Qwik City; it was never published as `@zitadel/sdk-qwik-city`. The CLI calls the framework `qwik-router` too (`zitadel setup --framework qwik-router`), and its docs page moved to `/docs/sdks/qwik-router`.
