The console's Projects page tells projects apart when there are many: each row shows the project's generated mark, its name with its site's host beneath, its ID with a copy button, and when it was created, and the selected project is marked Current. The list is sorted by name while it fits on one page, and its search shows from the start. New project, beside the title, opens a drawer with the CLI command that creates a project and connects your app.

The sidebar lists every screen before a project is selected. Opening one without a selection asks for a project first, on Projects headed "Continue to" that screen, and then goes on to it; signing in with several projects lands on Projects.
