The console's pickers (the project pill, the schema picker and the Events type filter) are named for screen readers, and the rule between their groups is drawn but not announced. The project pill's name now carries the project it shows, as "Switch project: <name>", and the sidebar's Search button is named by its label, "Search…". A highlighted option's badge, such as the Events filter's "Only failures", draws its text in the option's own colour, so it stays readable on the highlight in the dark theme. A reopened picker no longer fills its first row until it is pointed at or arrowed through.
