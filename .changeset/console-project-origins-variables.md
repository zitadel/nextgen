The Console's project page has an Overview tab and an Admins tab. Overview holds the project's name, its origins and its variables and secrets: origins can be added, edited and removed from the page, and variables are listed with the value each kind holds, a secret showing only that it is configured. Admins moves to its own tab. The projects list's row menu opens the page as "View project".
