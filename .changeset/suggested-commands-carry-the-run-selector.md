A refusal's follow-up command now carries the run's `--env`, `--env-file` and `--server`. A broken login flow, an attempt to remove the last way to sign in, a missing `api` path parameter, an `api --input -` or `--file -` with nothing piped in all named their command in the hint, without the selector, so following it could aim at the default project. Each now lists the command under `next_commands`.
