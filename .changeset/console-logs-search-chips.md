The console's Logs chooses its view (audit events, API requests, all) from a picker that says what each holds, and its sidebar keeps only the filters chosen from a list: time, category, and type or status. IDs, operations and the resource type go in the search, on a row of its own under the title, which shows each filter it set as a removable chip and takes a filter's name before a value (`actor:`, `resource:`, `resource_type:`, `app:`, `device:`); My activity moved from a toolbar icon into the empty search. Live shows a green dot while it reads, says under the toolbar when it last checked, and fades in the events it adds.
