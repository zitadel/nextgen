`zitadel origin add <pattern> --kind primary|preview`, `origin list` and `origin rm` manage the origins a project serves, with the project secret ([docs](https://preview.zitadel.com/docs/reference/cli/origin/add)). A primary origin is an exact URL, and a preview wildcard on a shared host needs a literal label of your own.
