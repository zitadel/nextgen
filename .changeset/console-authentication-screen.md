The console has an Authentication screen, between Users and Login flows in the project sidebar. Its Sign-in methods tab lists every method in use, Passkey, Password and each identity provider, with the user schemas that allow it and when they last changed. Its Identity providers tab lists the project's connections, newest first, with the schemas that use each one, and opens a read-only detail page with the slug, client ID, the schemas and login flows that reference the connection, and the stored document. The user schema screens also show the provider slugs a schema lists.
