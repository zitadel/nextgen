The console has an Authentication screen, between Users and Login flows in the project sidebar. Its Sign-in tab lists every user schema with the sign-in methods it allows, including one entry per identity provider it lists, and opens a schema's allowed methods with the login flows that use it. Its Identity providers tab lists the project's connections, newest first, and opens a read-only detail page with the slug, client ID, the schemas and login flows that reference the connection, and the stored document. The user schema screens also show the provider slugs a schema lists.
