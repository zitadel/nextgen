The command list that `zitadel --help` prints is now grouped by the task you are on: Getting started, Local server, Users and access, Sign-in, Project settings, Releases, API and events, and CLI. `doctor` sits with Getting started, `upgrade` with Project settings, and the generated resource commands follow the same groups. The headings are navigation only; no command changed its name or flags.
