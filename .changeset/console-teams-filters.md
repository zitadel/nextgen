The console's Teams directory can be searched by name and filtered by status. Search matches part of a name, ignoring case, across every team in the project rather than only the page on screen; the `Active` and `Deactivated` tabs narrow the list the same way. Both are kept in the page's address, so a filtered list can be linked, reloaded, and stepped back through.
