The console keeps the selected project when you go to Projects or Settings: the logo no longer swaps the project switcher to "All projects", and a screen chosen from the sidebar there opens in that project instead of asking for one again. On Logs, the search has its own row under the title, the sidebar's filters are easier to read, and "Only failures" is a shortcut inside the type list that ticks the failure types it selects. Searching Projects no longer reloads the screen while you type, and copying the loaded events says whether it worked.
