Add Solid, Svelte and Qwik SPA SDKs that wrap the zitadel-login / zitadel-logout web components, mirroring sdk-react and sdk-vue. Each exposes `ZitadelLogin`/`ZitadelLogout`, re-exports `configureZitadel`, and surfaces the widget's flow events as optional callbacks.
