The console's Add user and user edit forms now build their controls from the whole user schema: nested objects and identifiers, arrays, nullable types and enums can be entered and edited, descriptions and rules show as help, and errors appear on the affected field. A property no control can write shows its stored value and points to the CLI or API. The identifier is marked, hovering a label names the API property, and objects can be collapsed, with large ones starting closed.
