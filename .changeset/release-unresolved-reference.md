`POST /releases` validates a release's revisions against each other. A flow definition whose `user_schema`, or whose switch or pivot target flow, the release does not reference answers `400 rel.unresolved_reference` naming the flow and the handle. A flow that does not fit the user schema revision the release references answers `400 rel.invalid` naming the flow and the revision.
