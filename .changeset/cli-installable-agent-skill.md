Distribute the CLI's agent guidance as an installable Agent Skill. Any skills-compatible coding agent — Claude Code, Cursor, Copilot, Codex, and more — can now add it with `npx skills add zitadel/nextgen`, giving the agent guided, always-current instructions for scaffolding and managing Zitadel auth with the `zitadel` CLI. The skill also ships inside the `@zitadel/cli` package.
