The `zitadel-cli` agent skill now points agents at the sign-out button that apps generated by `zitadel setup` actually render, `zitadel-session-logout` inside `<zitadel-session>`, instead of `<zitadel-logout>`'s `.signout-btn`, which those apps don't render, and describes `typography.font_url`, which it said could not be set yet. It also says where `next_commands` sits in the JSON envelope, and tells agents to always pass `@alpha`, because bare `npx @zitadel/cli` runs an early `0.0.0` build. The `@zitadel/components` README now lists the sign-out hooks of `<zitadel-session>` and says how to reach the sign-out button of `<zitadel-logout>`, which has none.
