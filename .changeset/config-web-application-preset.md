`@zitadel/config` exports `webApplication()`, which builds an application document for a web app: one confidential OAuth client that signs users in with the authorization code grant and returns them to the redirect URIs you pass. `APPLICATION_PRESETS` lists the preset names. Both are also exported from `@zitadel/config/application-presets`, which runs in the browser.
