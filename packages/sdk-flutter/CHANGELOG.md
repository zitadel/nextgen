# Changelog

## 0.1.0-alpha.1

- Initial release: `ZitadelLogin` (native rendering of server-driven flow
  steps with localized labels, validation hints, error banners, and
  automatic handoff exchange), `ZitadelSession` / `ZitadelLogout`,
  `FlowController` for headless custom UIs, altcha captcha solving in a
  background isolate, and secure keychain-backed token/cookie stores.
