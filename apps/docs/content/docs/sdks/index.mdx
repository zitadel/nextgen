The preview publishes framework SDKs and shared components in one alpha package train.

## Packages

- `@zitadel/sdk-next`
- `@zitadel/sdk-nuxt`
- `@zitadel/sdk-react`
- `@zitadel/sdk-vue`
- `@zitadel/sdk-angular`
- `@zitadel/components`
- `@zitadel/api`

Prefer the CLI for app setup. Use the SDK docs when reviewing generated files, customizing routes, or integrating manually.
