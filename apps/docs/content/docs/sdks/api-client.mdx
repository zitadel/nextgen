`@zitadel/api` is generated from the OpenAPI source under `api/openapi/`.

It exposes:

- generated endpoint functions
- generated models
- Zod schemas
- MSW helpers
- runtime helpers for base URL and auth

## Usage

The package has no root export; import from its subpaths:

- `@zitadel/api/client` — `createZitadelClient`, a typed client bound to a base URL and an optional bearer token.
- `@zitadel/api/config` — `configureZitadel` and `getApi`, the shared browser configuration the components and SDKs use.
- `@zitadel/api/generated/model` — request and response types.
- `@zitadel/api/generated/endpoints/zitadelNextGen` — the endpoint functions behind the client, with `.zod` and `.msw` variants for the Zod schemas and MSW handlers. Call the endpoints through `createZitadelClient`: on their own they read a base URL and token shared across the process, which only the client sets. The MSW handlers need the optional peers `msw` and `@faker-js/faker`.

Call the API from server-side code:

```ts
import { createZitadelClient } from "@zitadel/api/client";

const client = createZitadelClient({
  baseUrl: process.env.ZITADEL_URL ?? "http://localhost:8080",
  token: process.env.ZITADEL_PROJECT_SECRET!, // server-side only
});

const project = await client.getProject(process.env.ZITADEL_PROJECT_ID!);
```
