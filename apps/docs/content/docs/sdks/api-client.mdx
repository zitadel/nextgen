`@zitadel/api` is generated from the OpenAPI source under `api/openapi/`.

It exposes:

- generated endpoint functions
- generated models
- Zod schemas
- MSW helpers
- runtime helpers for base URL and auth

Use the [API reference](/reference/api) to inspect endpoint shapes. Use package exports from `@zitadel/api` when writing CLI, SDK, or app code against the typed client.

<Callout title="Edit the OpenAPI source" type="warn">
  Do not hand-edit generated API package output. Update `api/openapi/**` and regenerate through the repo tasks.
</Callout>
