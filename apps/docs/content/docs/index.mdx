Zitadel is an identity platform: it handles sign-in, users, and sessions for your apps. This preview sets it up locally, keeps its configuration in your repository, and lets a person or a coding agent prove sign-in end to end.

Zitadel v4 stays maintained while this preview evolves. The preview is pre-release: APIs, CLI flags, packages, and docs can change before it becomes a future major version. The public product name may also change.

## What you can do today

The `@zitadel/cli` package sets up auth on your machine. `zitadel start` runs the released `@zitadel/server` npm binary. You need no Docker, Go, or source checkout ([Run Zitadel locally](/docs/guides/local-runtime)). `zitadel setup` scaffolds auth into a new app or adds it to yours.

The claim flow, which attaches a project to a team, works end to end. A local project needs no claim ([Claim](/docs/concepts/project-team-user#claim)).

## LLM support

This docs site offers:

- `/docs/llms.txt` for a compact index, each page by its Markdown URL.
- `/docs/llms-full.txt` for the full text of every page except the API operations.
- `/docs/<page>.md` for a page's Markdown (the overview is `/docs/index.md`). You can also request the page URL with `Accept: text/markdown`.
- `/docs/api/search?query=<query>` for search.
- `/docs/api/mcp` for MCP clients, with the tools `search`, `list_pages`, and `get_page`.
- `/docs/openapi.json` for the server's whole OpenAPI document.
