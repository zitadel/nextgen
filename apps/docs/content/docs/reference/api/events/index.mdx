title: Events

---

import { Card, Cards } from "fumadocs-ui/components/card";

Events are the project's audit trail: request, auth, session, admin, and entity
events, filterable by category and event type. The server can also deliver
them to a webhook as it stores them; [Event webhooks](/docs/reference/api/event-webhooks)
has a page per event type.
