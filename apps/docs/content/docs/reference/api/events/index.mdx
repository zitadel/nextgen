---
title: Events
description: List and read the project's audit events, such as request, auth, session, admin and entity events.
---

Events are the project's audit trail: request, auth, session, admin, and entity
events, filterable by category and event type. The server can also deliver
them to a project's webhooks as it stores them;
[Event webhooks](/docs/reference/api/event-webhooks) describes the request.
