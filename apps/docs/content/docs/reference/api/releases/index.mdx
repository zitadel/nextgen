---

import { Card, Cards } from "fumadocs-ui/components/card";

A release is an immutable snapshot of a project's configuration: one revision of
each resource, plus who made it, when, and from which commit. Creating a release
does not deploy it. Building a release from files and revoking one answer
`501 Not Implemented` today.
