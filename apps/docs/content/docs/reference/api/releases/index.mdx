---
title: Releases
description: OpenAPI operations for configuration releases.
---

A release is an immutable set of pinned revisions: at most one revision of each
schema, flow definition, and branding, plus who made it, when, and from which
commit. Identity provider connections and variables can't be pinned yet.
Creating a release does not deploy it. Building a release from files and
revoking one answer `501 Not Implemented` today.
