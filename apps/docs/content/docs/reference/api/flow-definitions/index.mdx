---
title: Flow definitions
description: Create and read the templates that describe sign-in, registration and recovery journeys.
---

Flow definitions are templates for user journeys such as login, registration,
and recovery. They describe the ordered capabilities a flow should resolve and
execute at runtime. Each create publishes a new revision under the flow's name.
A start request that names the flow runs its newest active revision; one
without a name chooses among all active revisions in the project.
