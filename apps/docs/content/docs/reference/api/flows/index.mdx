---
title: Flows
description: A running sign-in, registration or recovery journey in the browser. A flow is started, shows its current step and accepts each step submission.
---

A flow is a user journey that is running in a browser, such as a sign-in. It
resolves a flow definition and returns the current capability step. A capability
step is one step of the journey, such as a password prompt. A flow also accepts
the submission of each step.
