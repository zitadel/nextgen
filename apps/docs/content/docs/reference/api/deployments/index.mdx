A deployment will record which release is live on which targets, and when.
These operations are specified but answer `501 Not Implemented` today. Until
they ship, the server serves the newest revision of each schema, branding and
identity provider connection. It picks flows as [Deploy](/docs/guides/deploy)
describes.
