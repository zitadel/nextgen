A deployment will record which release goes live on which targets, and when.
These operations are specified but answer `501 Not Implemented` today. Until
they ship, the server serves the newest revision of each schema, branding, and
identity provider connection, and picks flows as [Deploy](/docs/cli/deploy)
describes.
