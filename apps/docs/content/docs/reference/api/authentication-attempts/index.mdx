---
title: Authentication attempts
description: Run one sign-in round by creating an attempt, issuing challenges, verifying proofs and creating the handoff token.
---

An authentication attempt is one sign-in round, and it expires 15 minutes after
creation. Call these operations to run a sign-in from your own client, or to
add factors to an existing session (step-up authentication).

The calls run in this order:

1. Create the attempt.
2. Issue a challenge, a request to prove one factor such as a password.
3. Verify the proof for that challenge. Repeat steps 2 and 3 until the attempt
   is `completed`.
4. Create the handoff token, the short-lived credential that a completed
   attempt hands to the session exchange.
5. Exchange the handoff token for a session in [Sessions](/docs/reference/api/sessions).

See [Sessions and auth attempts](/docs/concepts/sessions-auth-attempts) for the
concepts.
