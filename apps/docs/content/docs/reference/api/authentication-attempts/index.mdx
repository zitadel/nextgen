---
title: Authentication attempts
description: One short-lived round of proving who a user is, with factor challenges, proof checks and a handoff token that is exchanged for a session.
---

An authentication attempt is one round of proving who a user is. It covers
sign-in, registration, step-up and recovery. Step-up adds factors to an existing
session.

Use these endpoints to start an attempt and issue challenges for authentication
factors, such as a password or a passkey. Then verify the proofs and create a
handoff token. The handoff token is exchanged for a session.
