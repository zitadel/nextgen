---
title: Policies
description: The settings a project's operation is checked against, such as the minimum password length, published as immutable revisions.
---

A policy holds the settings that a project's operation is checked against. An
example is the minimum length a new password must have. A project has one policy
per operation. Each publish creates an immutable revision, and the newest one
applies the next time the operation runs. Settings left out are off, because
Zitadel applies no defaults.
