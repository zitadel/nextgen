---
title: Schemas
description: Create and read the schemas that define the shape of a project's user data.
---

A schema defines the typed shape of user data and of other configurable
resources. A user schema can designate which properties identify a user
(`x-identifier`) and which are shown as its name (`x-display`).

Create a schema, then list or read it by ID. See
[Flows and schemas](/docs/concepts/flows-and-schemas) for how schemas fit with
flow definitions.
