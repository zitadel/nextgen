---
title: Search
description: Find the users and teams of a project that match a text, in one request.
---

Search answers what a person types into one field: part of an email address, a
team's name, or an id copied from a log. One request looks through the types
you name and returns the best matches of each.

A result is a reference: its type, its id, a title and sometimes a subtitle.
Read the resource itself through its own operations, under
[Users](/docs/reference/api/users) and [Teams](/docs/reference/api/teams).

How text is matched and ranked can change between versions, so treat the
results as suggestions. To filter by an exact rule, or to page through every
match, use the type's query operation.
