---
title: Projects
description: Create a project, claim it for a team, and manage its origins and admins.
---

A project is the top-level boundary that holds users, sessions and their
sign-in configuration. You create one to give your app a place to sign users
in; [`zitadel setup`](/docs/get-started/quickstart) does it for you.

A common sequence:

1. Create the project. The response carries the project secret and the preview
   secret, and no other operation returns them.
2. Claim it. A project created before anyone signed in has no owning team. A
   [claim](/docs/concepts/project-team-user#claim) attaches it to a team, so
   that the team's members administer it. Start the claim, open the returned
   URL in a browser, and poll the claim's status until it completes.
   `zitadel claim` runs these steps.
3. Add origin patterns for the URLs that may use the project.

A claim must finish within 14 days of the project's creation. After that the
project can no longer be claimed.
