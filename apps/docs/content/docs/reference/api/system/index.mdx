title: System
description: Check the server's liveness and readiness with the probes at /livez and /readyz.
---

System endpoints expose the service probes used by local development,
automation, and deployment health checks. Point a probe at the root path,
`/livez` or `/readyz`: like every operation they also answer under `/api/v1`,
but the root is where the probes stay.
