---
title: Databases
description: Choose SQLite, PostgreSQL, or Spanner for the Zitadel server.
---

Zitadel stores projects, users, sessions, and related state in a SQL database. Configure exactly one database dialect. When `database:` is omitted, the server uses **SQLite** at `<server.data_dir>/zitadel.db`.

- **SQLite** — local development, `zitadel start`, and small single-node or homelab deployments (single-writer limits apply).
- **PostgreSQL** — production and the Docker Compose operator stack.
- **Spanner** — production on Google Cloud Spanner.

PostgreSQL and Spanner are the production options. To run the server with the CLI, see [Run Zitadel locally](/docs/guides/local-runtime). For YAML and environment examples, see the repository [configuration guide](https://github.com/zitadel/nextgen/blob/main/docs/quick-start/configuration.md).
