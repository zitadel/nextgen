- The Users table stays within its width however many properties a schema has: the User column and the row menu stay in view while it scrolls, schema properties appear once pinned from the Columns menu, and the rest read in one Attributes column that opens them as fields, JSON or YAML. The Team column is now "Member of".
- The user schema screen badges the property a schema signs users in with (`x-identifier`) and the properties that make up their display name (`x-display`), and the attribute labels on a user's page line up with their inputs.
- A user's page shows the schema's name beside its revision box, which now holds only the revision id.
- The theme button on the Branding screen shows which side the preview paints, and opens a menu of From branding, Light and Dark, without a side the branding does not publish.
