| [059](059-per-environment-variables-and-secrets.md)       | Per-Environment Variables and Secrets | Draft | Outcome of #967: a variable is `(name, owner, value, is_secret)` referenced as `${{ NAME }}` with no `vars.`/`secrets.` namespace; a whole-value placeholder keeps the variable's JSON type, an embedded one renders into the string, an unresolved one stays literal.
